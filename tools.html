Clinical · MCP Server

uk-evidence MCP

A Model Context Protocol server giving Claude live, point-of-care access to UK clinical evidence — NICE guidance and quality standards (search plus full chapter text), NICE CKS primary-care summaries, MHRA drug-safety articles, and PubMed search and abstracts. So Claude answers from the current guideline, not its training data.
